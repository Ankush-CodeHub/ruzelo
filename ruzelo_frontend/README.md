# Ruzelo Frontend (रुज़ेलो)

### Next-Generation Cinematic Music Streaming Client built with Flutter & Custom GLSL Shaders.

---

## 🚀 Key Features

- **Integrated Header Search**: Universal real-time debounced search built into the app bar.
- **100% Real Music Streaming**: Live music distribution network integration with full-length master audio playback.
- **Frosted Glass Mini-Player**: Complete playback controls (Previous, Next, Play/Pause, Favorite toggle) with interactive progress scrubber.
- **Signature 3D Full-Screen Player**: 3D parallax tilt, 360° rotating vinyl disc, 60 FPS waveform visualizer, and haptic particle bursts.
- **Liquid Glass & Atmospheric Mesh Shaders**: Custom GLSL fragment shaders dynamically adapting to audio energy and genre palettes.
- **Session Auto-Resume**: Automatic persistence and recovery of the user's last-played track on app startup.

---

## 🏃 Running Locally

```bash
# Install dependencies
flutter pub get

# Run on web dev server
flutter run -d web-server --web-port 5050 --web-hostname 127.0.0.1
```

## 🧪 Testing

```bash
flutter test
```
